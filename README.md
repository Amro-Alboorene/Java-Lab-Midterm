# Java Lab Midterm Project

## Description
This project was developed as part of a Java programming midterm exam at Zarqa University.
The project consists of two main tasks:
1. Solving a mathematical expression using randomly generated values.
2. Calculating the total bill including tax and tip based on user input.

## Features
- Random number generation
- Mathematical operations using Java Math library
- User input handling with Scanner
- Tax and tip calculation
- Formatted output

## Academic Context
- Course: Java Programming
- Level: First-year Software Engineering
- Score: 30/30
